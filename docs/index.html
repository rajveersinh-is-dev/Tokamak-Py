What it does

Tokamak-Py treats a plasma as an N-body system. Every particle feels the softened Coulomb force of every other particle plus any external electric and magnetic fields, and is advanced with a symplectic Boris integrator. It scales from a few hundred particles to a few thousand using Barnes-Hut tree decomposition, and ships with a desktop dashboard, a headless CLI, and a benchmark suite.

It is a kinetic (particle) code with prescribed fields, not a magnetohydrodynamics solver.

Features

  • Symplectic Boris integrator (2D-3V and 3D-3V) — an exact magnetic rotation with a split electric push, so energy stays bounded over long runs.
  • Barnes-Hut quadtree (2D) and octree (3D) solvers at O(N log N), with an exact O(N²) direct solver used as ground truth and for small systems.
  • Field models for a tokamak torus (toroidal + poloidal, with a safety-factor profile), a 2D poloidal slice, a magnetic mirror bottle, a Farnsworth-Hirsch fusor, and an orthogonal E × B drift.
  • Reflective limiters — circular, toroidal and spherical boundaries.
  • PyQt6 dashboard with live confinement, tracer orbits, energy telemetry and a Maxwell-Boltzmann histogram.
  • Headless CLI and Python API for running presets, saving diagnostic figures and benchmarking the solvers.

Performance

Install and usage

Requires Python 3.10+. The dashboard needs PyQt6 and PyQtGraph; the CLI, Python API and tests run without a display.

git clone https://github.com/rajveersinh-is-dev/Tokamak-Py.git
cd Tokamak-Py
pip install -r requirements.txt

python main.py          # launch the interactive dashboard

Headless commands:

python main.py run --preset tokamak_2d --particles 600 --steps 800 --output fig.png
python main.py presets
python main.py benchmark --theta 0.25 --save-chart bench.png

From Python:

from tokamak_py import PhysicsEngine

engine = PhysicsEngine(preset="tokamak_2d", n_particles=600, solver="barnes_hut")
for _ in range(500):
    engine.step()

print(engine.kinetic_energy, engine.potential_energy)
print("relative energy drift:", engine.get_relative_energy_drift())
